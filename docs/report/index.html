대화가 끊겨도
검사는 이어진다

T04 정보판의 재방문 기록 병합 한 기능을 두 AI 세션이 차례로 개선했다. 두 번째 세션은 앞 대화 없이 저장소와 7항목 인수인계 문서만 읽고 같은 고정 검사 10개를 완료했다.

10개작업 전 고정 검사

01 / 고정한 문제

재방문하면 새 날짜도 보이게

공통 상한 30분 · 35회

원래 정보판은 브라우저 저장소에 기록이 한 건이라도 있으면 새 공개 일별 기록을 가져오지 않았다. 개선 목표는 재방문 때 새 날짜를 안전하게 합치고, 같은 날짜는 조회 시각이 더 최신인 값만 남기는 것이다. 공개 JSON이 손상되면 기존 값은 유지한다.

두 세션에 준 최초 기능 요청과 검사 목록은 시작 소스에 먼저 고정했다. 원형 소스의 결과는 4/10 통과였다. 고정 파일 SHA-256은 3fbed28349ef68f076e171a22de4d86557ca4639e160b873d20e20bcd12370a8이다.

02 / 이름을 가린 비교

같은 상한, 같은 검사

오류 회차 = 10개 검사 중 하나 이상 FAIL이 난 전체 실행 회차

익명 실행실제 작업시간도구 호출오류 회차고정 검사 통과시작 → 종료 버전
실행 ①1분 20초13회1회8 / 10f41c51a… → e6e15b9…
실행 ②1분 10초15회0회10 / 10e6e15b9… → 49fd870…

모델·서비스 이름은 이 판정 표에서 가렸다. 두 세션의 모델 ID는 서로 다르며 작업 순서와 원자료는 저장소의 과정 기록에 보관했다. 소스 추가·삭제 줄 수로 계산하는 재작업량은 고정 버전 쌍을 사용해 제출 뒤 산출한다.

05 / 문서로 이어받기

한 페이지, 일곱 항목

목표현재 상태실행 명령통과 검사남은 문제다음 행동건드리지 말 것

A가 남긴 문서와 B가 받은 문서의 SHA-256은 둘 다 9b94778b717394cb8732f2f523be327cac4a0c557e512236d7a412044de3a08e이다. B가 보고한 문서 누락은 없음. 대화 전문은 제출 자료에 포함하지 않았다.

06 / 학생 판단

다음 작업의 도구 선택 기준

고정 검사 통과 수를 우선 비교하고, 같으면 도구 호출 수가 적은 쪽을 고른다.

AI에게 맡긴 일. 고정 검사 실행, 공개 기록 병합의 부분 구현과 인수인계, 다른 모델의 이어받기 및 최종 검사.

직접 판단한 일. 동일한 검사·시간·호출 상한으로 비교하고 위 기준으로 다음 도구를 선택한다. 따르지 않은 AI 제안. 없음. 제안을 고정 검사와 과제 범위에 대조했고 거절할 제안은 없었다.
